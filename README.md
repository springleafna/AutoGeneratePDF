🌟 欢迎使用【AutoGeneratePDF】

AutoGeneratePDF 是一个用于批量导出打印页面 PDF 的小工具。输入一个或多个打印页网址后，程序会自动打开网页，点击“一键导出PDF”按钮下载包含全部四个版本的压缩包，自动解压并把 PDF 保存到桌面的日期文件夹中。

📌 使用方法

1. 双击打开 `print_tool_gui.exe`
   → 弹出窗口后，输入打印页面网址（如：https://admin.lxll.com/#/print/...）
   → 点击“✚ 添加网址”，可继续添加多个待处理网址

2. 点击“✅ 开始打印”

3. 程序会自动：
   - 打开 Edge 浏览器
   - 点击网页上的“一键导出PDF”按钮
   - 网站生成包含中文、英文、中英文、音标四个版本的 ZIP 压缩包并自动下载
   - 自动解压四个 PDF 文件到桌面的 AutoGeneratePDF 日期文件夹，并删除压缩包

4. 弹窗显示“全部任务完成”后，即可查看结果

📂 输出位置

所有 PDF 文件会保存到：

`桌面 → AutoGeneratePDF → YYMMDD（当天日期文件夹）`

例如当天日期为 2025-09-14，则文件夹为：

`桌面 → AutoGeneratePDF → 250914`

你会看到类似以下四个文件（文件名与压缩包内一致）：

- 学习资料_陈唤唤_2025-09-14_中英文.pdf
- 学习资料_陈唤唤_2025-09-14_英文.pdf
- 学习资料_陈唤唤_2025-09-14_中文.pdf
- 学习资料_陈唤唤_2025-09-14_音标.pdf

💡 文件夹和文件说明

- 每天都会自动创建新的日期文件夹，不会和其他日期混在一起
- 每个网址会下载一个压缩包，解压后压缩包会自动删除，文件夹里只保留 PDF
- 如果同名 PDF 已存在，程序会自动生成 `文件名(1).pdf`、`文件名(2).pdf`，避免覆盖旧文件
- 支持一次输入多个网址，程序会按顺序逐个处理

❗ 注意事项

- 需确保电脑已安装 Microsoft Edge 浏览器
- 请确保电脑已联网，且打印页面可以正常打开
- 网页必须包含“一键导出PDF”按钮
- 不要关闭程序窗口，直到出现“全部任务完成”弹窗
- 如果浏览器启动失败，请检查 `msedgedriver.exe` 是否和 Edge 浏览器版本匹配
- 可在 Edge 地址栏输入 `edge://settings/help` 查看浏览器版本
- 获取 msedgedriver.exe 驱动程序最新版本网址：https://developer.microsoft.com/en-us/microsoft-edge/tools/webdriver/
- 如遇问题，请截图发给技术支持
